# 发票报销快速入门

> 适用版本：v0.1.0
> 适用电脑：Apple Silicon Mac（M1 或更新芯片）
> 适用系统：macOS 11 或更高版本

## 先了解这件事

绑定邮箱后，App 会帮你收集邮件附件并识别发票，但不会直接完成报销。你仍需要完成这条路径：

![从邮箱发票到报销材料的工作流](assets/workflow.png)

## 1. 安装与绑定

1. 从分享者处获取 `发票报销_0.1.0_aarch64.dmg`，打开后将《发票报销》拖入“应用程序”。
2. 第一次打开时，如果 macOS 阻止运行，在 Finder 中右键点击 App，选择“打开”，再次确认“打开”。也可在“系统设置 -> 隐私与安全性”中选择“仍要打开”。
3. 进入 App 的“设置”页，选择 Gmail 或 QQ 邮箱。
4. 输入邮箱地址和应用专用密码或授权码。这不是你平时登录邮箱的密码。
5. 保持“启用此账号”开启，点击“测试连接”。看到“连接成功”后，点击“保存账号”。

![邮箱账号设置和连接成功画面](assets/mailbox-setup.png)

> 安全提醒：当前分享版未经 Apple 签名和公证。只从你信任的分享者获取安装包，不要关闭 macOS 的整体安全保护。

## 2. 同步与确认

### 立即同步

1. 打开“控制台”。
2. 点击右上角“立即同步”。App 会同步所有已启用的邮箱账号。
3. 同步完成后，查看“最近新增”和“待确认”数量，然后打开“待处理池”。

如果你不想等待邮箱同步，可以在“待处理池”中直接拖入票据，或点击“选择文件”。

### 检查待处理池

1. 先处理“待确认”。点击一张发票，打开“票据详情”。
2. 对照左侧预览，检查分类、开票日期、建议月份、金额、城市和主体。
3. 有错就直接修正；识别结果明显不对时，点击“重新识别”。
4. 确认无误后，点击“保存并确认”。发票状态应变为“可纳入批次”。

![票据预览、识别结果和最终值编辑画面](assets/invoice-review.png)

> “识别失败”需要检查文件后点击“重新识别”。“疑似重复”需要选择“确认保留”或“删除重复”。这两类票据在处理前不能进入报销批次。

## 3. 批次与导出

1. 打开“报销批次”，点击“新建批次”。
2. 选择“按月”或“自定义范围”，设定时间后点击“创建批次”。
3. 进入批次详情，点击“加入推荐票据”，或使用“调整票据”和“归属所选票据”。
4. 检查票据张数、合计金额和“待确认”数量。待确认必须为 0。
5. 点击“导出报销包”。看到“报销包已生成”后，点击“在文件夹中显示”。

![报销包导出成功画面](assets/batch-export.png)

导出目录中应有四个文件：

- `merged.pdf`：合并后的发票 PDF。
- `reimbursement.xlsx`：报销明细表。
- `originals.zip`：原始票据压缩包。
- `manifest.json`：本次导出的清单与校验信息。

## 遇到问题

- **点击“立即同步”后没有发票**：确认账号已启用，邮件中有受支持的附件，并查看“待处理池”的“全部”标签。
- **不能导出**：先处理识别失败、疑似重复和未确认票据。
- **关闭窗口后找不到 App**：主窗口只是被隐藏。在 macOS 菜单栏找到《发票报销》图标，选择“显示发票报销”。
