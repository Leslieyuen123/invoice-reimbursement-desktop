# 《发票报销》用户手册设计规格

日期：2026-07-20  
状态：设计已确认，待用户审阅书面规格  
适用版本：发票报销 v0.1.0

## 1. 目标

为《发票报销》桌面 App 制作一套可以直接分享给其他用户的中文使用手册。手册需要同时服务两类读者：

1. 首次接触 IMAP、邮箱授权码和报销材料导出的普通办公用户。
2. 已经了解邮箱设置，只需要快速查找某个页面或故障处理方法的熟练用户。

文档的首要成功标准是：一名新用户只根据手册，即可在 Apple Silicon Mac 上完成安装、绑定邮箱、同步发票、检查识别结果、创建报销批次并导出完整报销材料。

## 2. 交付物

最终交付四个用户可见文件：

1. `docs/user-guide/invoice-reimbursement-user-manual.md`：完整用户手册 Markdown 源文件。
2. `docs/user-guide/invoice-reimbursement-quick-start.md`：2–3 页快速入门 Markdown 源文件。
3. `output/pdf/invoice-reimbursement-user-manual-zh-cn.pdf`：可分享的完整手册 PDF。
4. `output/pdf/invoice-reimbursement-quick-start-zh-cn.pdf`：可单独分享的快速入门 PDF。

截图、图标和流程示意图统一放在 `docs/user-guide/assets/`。生成 PDF 时的中间文件放在 `tmp/pdfs/`，不作为最终交付物。

## 3. 手册组织方式

采用“任务流程型双手册”方案。完整手册按用户完成一次报销的真实顺序组织，快速入门只保留完成第一次报销的最短路径。

不采用纯粘页面罗列的写法，因为这会让新用户难以理解“同步、识别、确认、归批次、导出”之间的先后关系。在完整手册附录中提供页面索引，满足熟练用户的查询需求。

## 4. 完整用户手册结构

### 4.1 开始之前

- App 用途、工作边界与数据隐私。
- 适用设备：Apple Silicon Mac（M1 或更新芯片）。
- 最低系统版本：macOS 11。
- 当前版本为未签名安装包，首次打开需要用户确认系统安全提示。

### 4.2 安装与首次打开

- 下载 DMG、打开安装镜像和将 App 拖入“应用程序”。
- 处理 macOS “无法验证开发者”的首次打开流程。
- 识别并进入控制台。

### 4.3 认识 App

- 控制台：同步入口与处理概览。
- 待处理池：识别、修正和确认发票。
- 报销批次：组织发票并导出材料。
- 设置：邮箱、同步周期、导出目录与后台同步。

### 4.4 绑定邮箱

- Gmail 和 QQ 邮箱的适用说明。
- 授权码或应用专用密码与普通登录密码的区别。
- Gmail 默认地址 `imap.gmail.com:993`。
- QQ 邮箱默认地址 `imap.qq.com:993`。
- 必须先点击“测试连接”，看到“连接成功”后再“保存账号”。
- 账号必须保持启用才会参与同步。
- 同步间隔可设为 5–1440 分钟。

### 4.5 启动发票处理

手册必须明确说明：绑定邮箱不等于 App 已经替用户完成报销。App 会同步邮件附件并尝试识别发票，但用户仍需检查、确认、归入批次并导出。

三种启动方式都需要说明：

1. 在控制台点击“立即同步”，同步所有已启用账号。
2. 在设置中开启后台自动同步，按设定间隔运行。
3. 在待处理池拖入文件，或点击“选择文件”手动导入 PDF 或图片。

### 4.6 待处理池与发票确认

- 说明“待识别”、“待确认”、“识别失败”、“疑似重复”和“可纳入批次”的含义。
- 检查预览和自动识别字段。
- 修正分类、日期、月份、金额、城市、公司、备注和标签。
- 识别结果不可用时点击“重新识别”。
- 点击“保存并确认”后，发票才可正常进入报销批次。
- 疑似重复项提供“确认保留”和“删除重复”两种处理方式。

### 4.7 报销批次

- 创建月度批次或自定义日期范围批次。
- 通过“调整票据”和“归属所选票据”管理批次内容。
- 识别失败和疑似重复的发票不能归入批次。
- 批次中存在未确认发票时，系统必须阻止导出。

### 4.8 导出报销材料

导出包内容需要与当前 App 实际输出保持一致：

- `merged.pdf`：合并后的发票 PDF。
- `reimbursement.xlsx`：报销明细表。
- `originals.zip`：原始文件归档。
- `manifest.json`：导出清单与基本元数据。

手册同时说明如何在设置中更改导出目录，以及如何找到已生成的报销包。

### 4.9 日常运行与本地数据

- 关闭主窗口只会隐藏 App，不代表完全退出。
- 可通过菜单栏图标重新打开、立即同步或退出。
- 应用数据位于 `~/Library/Application Support/com.invoice-desk.desktop/`。
- 提供本地数据备份和迁移注意事项，但不延伸为企业级灾难恢复方案。

### 4.10 常见问题和故障排查

至少覆盖以下实际阻塞场景：

1. macOS 阻止首次打开。
2. 邮箱测试连接失败或授权码无效。
3. 点击同步后没有发现发票。
4. 附件识别失败。
5. 发票被标记为疑似重复。
6. 发票无法归入批次。
7. 未确认发票导致导出被阻止。
8. 导出目录无权限或导出失败。
9. 关闭窗口后找不到 App。

### 4.11 附录

- 顶层页面和常用按钮索引。
- 发票状态快速对照表。
- 导出文件对照表。
- 版本与适用环境说明。

## 5. 快速入门结构

快速入门控制在 2–3 页，并可脱离完整手册单独分享。内容分为三段：

1. 安装与绑定：安装 DMG、首次打开、输入邮箱授权码、测试连接并保存账号。
2. 同步与确认：点击“立即同步”，在待处理池检查字段，点击“保存并确认”。
3. 批次与导出：创建批次，归属发票，导出并确认四类输出文件。

只有会阻止这条最短路径的注意事项才放入快速入门；其余细节通过指向完整手册处理。

## 6. 视觉与信息设计

采用用户已确认的“浅色编辑式文档 + 深色 App 截图”方向。

### 6.1 版式

- 以白色和中性灰作为阅读底色，保持专业、安静和高对比度。
- 章节号、步骤编号和关键标注使用单一强调色。
- 保持稳定的标题层级、页边距、页脚、页码和版本标识。
- 完整手册使用可扫读的标题和小节，避免长段连续叙述。
- 快速入门使用更大的步骤号和更少的辅助文字。

### 6.2 截图和示意图

- 关键按钮、页面和对话框使用当前 App 的真实截图。
- 邮箱密码、授权码和发票内容使用模拟数据，不使用任何真实账号或个人信息。
- 对截图中的模拟邮箱、公司、金额和发票号进行二次脱敏检查。
- 每张截图主要解释一个操作，必要时对操作区域局部放大。
- “同步 → 识别 → 确认 → 归入批次 → 导出”和发票状态变化使用结构化流程图，不依赖长文解释。

### 6.3 分层说明

每个主要步骤优先使用以下顺序：

1. 用户要做什么。
2. 在哪里点击或输入。
3. 正常情况下会看到什么。
4. 如果结果不同，转到哪个故障排查条目。

普通用户不需要理解底层协议；IMAP 等技术信息只在设置说明或故障排查中出现。

## 7. 内容准确性与隐私

### 7.1 事实来源

- 页面名称、按钮文案、状态和错误提示以 v0.1.0 当前界面和自动化测试为事实来源。
- 邮箱、同步、导出和数据目录细节以当前实现与运维文档为事实来源。
- 系统要求以已发布的 Apple Silicon 构建配置为事实来源：macOS 11 或更高版本，不声称支持 Intel Mac。
- 手册不描述当前 App 尚未提供的企业审批、云同步、Apple 公证或 App Store 发布能力。

### 7.2 安全表述

- 明确提示用户输入邮箱授权码或应用专用密码，不输入普通邮箱登录密码。
- 不在手册、截图、日志或示例中记录任何真实凭据。
- 未经代码和实际行为验证的隐私或安全承诺不写入手册。

## 8. 验证方案

### 8.1 流程验证

使用模拟或测试发票完成一次端到端操作：

1. 打开 App 并进入控制台。
2. 启动邮箱同步，或手动导入发票。
3. 在待处理池检查和确认发票。
4. 创建报销批次并归属发票。
5. 导出报销包。
6. 确认导出包中存在 `merged.pdf`、`reimbursement.xlsx`、`originals.zip` 和 `manifest.json`。

快速入门的每一个步骤必须与这条通过验证的路径一致。

### 8.2 内容校对

- 核对所有页面名、按钮名、状态名和输出文件名。
- 检查手册中的链接、目录、页面引用和故障排查跳转。
- 检查截图中不包含真实邮箱、授权码、发票号、公司名或个人路径。
- 在手册封面或版本页明确标记 v0.1.0 和适用环境。

### 8.3 PDF 视觉验证

- PDF 使用支持简体中文的嵌入字体。
- 生成后将每一页渲染为图片并逐页检查。
- 不允许中文缺字、截图模糊、文字被截断、图文重叠、页码缺失或页边距失衡。
- 确认完整手册与快速入门均能独立打开、阅读和分享。

## 9. 维护方式

- Markdown 是内容事实来源，PDF 是发布用产物。
- 手册封面和版本页包含适用 App 版本，界面或行为变更时同步更新。
- 截图按章节和操作命名，避免使用无语义的编号。
- 完整手册和快速入门共享关键事实，但分别生成 PDF，不把快速入门仅作为完整手册内的附录。
- 本地可视化讨论文件位于 `.superpowers/`，实施时将该目录加入 `.gitignore`，不纳入手册产物或代码提交。

## 10. 范围外

以下内容不在本次手册制作范围内：

- Intel Mac 安装与兼容性说明。
- Gmail 和 QQ 邮箱之外的邮箱服务商专用教程。
- Apple 开发者签名、公证和 App Store 上架教程。
- 企业报销审批、财务制度或税务合规指导。
- 尚未在 v0.1.0 中提供的云同步、多用户或管理员功能。

## 11. 已确认设计结论

1. 产出完整手册和独立的 2–3 页快速入门。
2. 以普通办公用户可理解的写法为基础，同时提供熟练用户需要的快速索引和进阶说明。
3. 关键操作使用真实 App 截图，流程和状态使用示意图。
4. 视觉风格采用浅色编辑式文档，与深色 App 界面形成清晰对比。
5. 所有操作、系统限制和导出文件名称以 v0.1.0 实际行为为准。
6. 手册明确告知用户：邮箱绑定和同步只是收集与识别阶段，导出前仍需要人工检查和确认。
